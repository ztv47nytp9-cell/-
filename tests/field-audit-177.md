# VICTOR 177 후속 감사

가상 프로필로만 검사했다. 아래는 **새로 조사한 40개 항목**이지 서로 독립적인 확정 버그 40개가 아니다. 같은 원인의 사례는 다음 수정 때 한 번에 처리한다. 운영 데이터의 손상이나 실제 서비스 장애를 관측했다는 뜻이 아니다.

## 추가 검증이 필요한 7가지 (버그로 계산하지 않음)

34. iPhone PWA에서 숫자 키패드의 중간 입력(마이너스만 입력, 소수점만 입력) 후 커서·오류 복구.
35. iPad 하드웨어 키보드에서 박스 수 → 다음 품목 수량 이동과 한글 조합 Enter 간섭.
36. 저장소 차단 상태에서 Safari의 실제 복구 화면과 백업 불가 안내 접근성.
37. 한 기기가 공유본 확인을 마친 직후 다른 기기가 다시 올리는 짧은 경쟁 구간. 실제 데이터는 쓰지 말고 모의 서버로 시점 제어.
38. 웹앱을 백그라운드로 보낸 상태에서 OS가 종료할 때 마지막 등록 초안이 디스크에 기록되는지.
39. 전체 장비·운용·실사 이력이 쌓인 실제 규모에서 검색/선택창 첫 터치가 지연되는지. 가상 대량 데이터로 측정 필요.
40. 업데이트 전 입력 중인 다른 탭이 있는 경우, 구버전·신버전 탭에서 번갈아 저장할 때 충돌 안내 및 복구 가능 여부.
